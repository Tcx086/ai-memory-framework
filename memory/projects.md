# Project Index


## Purpose

This file provides an index of long-term projects.

It only stores:

- Project name
- Location
- Description
- Status summary

Note:

Status Summary is a historical confirmation snapshot. It is NOT the current real project status. For current status, read the project's internal STATUS.md.

This index is Layer 2 Authoritative Memory only for project navigation metadata and its dated snapshots. It is not authoritative for current technical facts, and Experience Memory results must not update it without validation and authorization.

Detailed technical information should stay inside the project repository.

# Project Rules


When working on a project:

1. Read this index only when needed to locate or identify the project.
2. Locate the project repository from the index or the user's current instruction.
3. Read only the project-specific documents relevant to the task.
4. Treat project-internal documents as authoritative for current status and technical facts.
5. Query an available Experience Memory Provider only when historical context is useful, after loading the relevant project authority.
6. Treat recalled results as historical evidence and resolve every conflict in favor of the project-internal authoritative document.
