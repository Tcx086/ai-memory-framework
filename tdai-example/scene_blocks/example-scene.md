## Overview

This is an example scene block generated by TDAI. Scene blocks are narrative summaries of related experience, automatically extracted from conversation history.

## What Scene Blocks Contain

- **Evolution trajectory**: How a project or topic developed over time
- **Key decisions**: Important choices made during the process
- **Pitfalls encountered**: What went wrong and how it was resolved
- **Patterns observed**: Recurring behaviors or preferences

## What Scene Blocks Do NOT Contain

- Current project status (check STATUS.md)
- Authoritative architecture (check ARCHITECTURE.md)
- Confirmed decisions (check DECISIONS.md)
- Known bugs (check BUGS.md)

## How to Use This

Scene blocks are historical evidence. They help you understand:
- What was tried before
- Why certain approaches were chosen
- What pitfalls to avoid
- How the user's preferences evolved

Always validate against authoritative files before acting on scene block content.

## Template

Replace this content with actual scene blocks generated by TDAI. Each scene block should:
- Focus on one coherent topic or project
- Include timestamps for key events
- Track the evolution of decisions and approaches
- Note unresolved questions or ongoing issues
